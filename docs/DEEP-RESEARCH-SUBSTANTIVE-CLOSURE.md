## 2. Financial scope: useful analysis without false completeness

The implemented financial deliverable is a dated, conditional operating-income-to-cash-flow
bridge. Tax, D&A, capex, working-capital movement and commitment overlap are
explicit, source-anchored assumptions. Historical cash-flow reconciliation and
forecast assumptions are different objects. A six-month amount is not a reported
quarterly amount; an aggregate mixed balance-sheet row is not pure operating
working capital.

Fiscal cash flows can be evaluated on their actual dates. A calendar conversion
is needed only when the selected model requires it; it is not an unconditional
prerequisite for every useful cash-flow calculation. Changing the model date does
not supply an unobserved historical roll-forward.

Keep four separate conclusions:

| Output | Required work beyond a conditional operating bridge |
| --- | --- |
| Conditional operating cash generation | Explicit reviewed assumptions, dated arithmetic, commitment overlap and retained limitations |
| Operating-asset value | Reviewed cash-flow horizon, discounting, terminal economics and model linkage |
| Equity/per-share value | Realizable nonoperating assets, liabilities, tax/lease consistency and dated diluted capitalization |
| Company-wide funding adequacy | Legally available liquidity, all material dated uses, restrictions and contingencies |

Neither an arithmetic review nor a source-authentication check is economic
underwriting or approval of the financial case. Unresolved obligations must not
